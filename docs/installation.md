# Installation

## From source (recommended for development)

```bash
git clone https://github.com/sensorlab/eCAL.git
cd eCAL
pip install -e ".[dev]"
```

## From PyPI

```bash
pip install ecal-energy
```

## Building these docs

To build this documentation locally, install the `docs` extra:

```bash
pip install -e ".[docs]"
cd docs
make html
```
